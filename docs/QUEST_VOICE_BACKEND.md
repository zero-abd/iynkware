# Quest voice backend

This optional service gives a native Meta Quest Unity build a bounded push-to-talk voice loop:

`Quest microphone → HTTPS upload → Gemini Live WebSocket → native audio reply → WAV playback`

The Gemini key stays on the server. The APK contains only a replaceable demo client token. For the hackathon this is intentionally a turn-based Quest-to-backend flow; the backend uses Gemini Live's stateful WebSocket and native audio response.

## Run locally

```bash
cd quest-voice-backend
cp .env.example .env
# Export the values from .env in your shell, then:
npm test
npm start
```

`GET /health` is public. `POST /v1/voice/turn` requires `X-Client-Token` and multipart fields `audio`, `sessionId`, `scenario`, `objective`, `learnerLevel`, `currentStep`, `lastAction`, and `locale`.

## Deploy on Render

The root `render.yaml` defines a free Docker web service using `quest-voice-backend/Dockerfile`. Create a Blueprint from this repository after the repository owner approves cloud-resource creation. Supply `GEMINI_API_KEY` when Render asks; `CLIENT_TOKEN` is generated by Render.

After deployment:

1. Confirm `https://SERVICE.onrender.com/health` returns `ok: true`.
2. Copy the generated `CLIENT_TOKEN` from the Render environment.
3. Copy `integrations/unity/VoiceAssistant` into the Unity project's `Assets/Scripts` directory.
4. Add `VoiceAssistantClient` and `AudioSource` to a GameObject, set the HTTPS base URL and client token, then connect a world-space button with `PushToTalkButton`.
5. Add Android permissions for `android.permission.RECORD_AUDIO` and `android.permission.INTERNET` and request microphone permission at runtime.

Do not commit either secret. The demo token is extractable from an APK, so rotate it after the event. Production use should replace it with device identity and per-user quotas.

## Quest build settings

- Android / Meta Quest target
- OpenXR
- IL2CPP and ARM64
- Internet Access: Require
- A visible disclosure that voice is AI-generated and the recording is sent to the configured provider

Conversation memory is process-local and expires. Keep one instance for the demo; use a durable store before horizontal scaling.

The demo service also caps each instance at 30 accepted voice turns per minute and two concurrent Gemini Live turns. These are cost and overload guards, not a substitute for per-user authentication in production.
